<h1 align="center">@autlantic/billing-engine</h1>

<p align="center">
  Subscription and invoice engine for Autlantic recurring USDC billing on Base.
</p>

---

Handles subscription lifecycle, invoices, refunds, sandbox charges, and webhook event generation. Usually consumed through [`@autlantic/payments-recurring`](https://www.npmjs.com/package/@autlantic/payments-recurring).

## Install

```bash
npm install @autlantic/billing-engine
```
