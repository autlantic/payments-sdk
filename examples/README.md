# Examples

Runnable apps that show how to integrate Autlantic Payments.

| Example | What it shows |
|---------|----------------|
| [`subscription-store`](./subscription-store) | **One-time** USDC checkout (`@autlantic/chain-evm`) and **recurring** subscriptions (`@autlantic/payments-recurring`) in one Next.js store |

```bash
pnpm example:store
# → http://localhost:3040
```
